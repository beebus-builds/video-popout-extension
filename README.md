# video-popout-extension

Pop any video into a floating always-on-top window. Picker with thumbnails, hover button, multi-popout, whole-tab capture, and pro controls.

## Install (Load unpacked)
1. Open chrome://extensions -> enable **Developer mode**.
2. **Load unpacked** -> select this folder (E:\extension).
3. Play a video -> click the toolbar button or press Alt+P.

## Features
- One-click Picture-in-Picture, per-video picker, and combined multi-video floating window (Document PiP).
- Hover Pop button, iframe + Shadow DOM scanner, ad/DRM hints, SPA-friendly repopout.
- Whole-tab capture window, Side Panel Theater, sleep timer, auto-pause/resume.
- Pro playback: boost to 200% + EQ, A-B loop, frame screenshot, speed/loop/seek/mute controls.
- Per-site Always/Never rules, import/export, welcome + privacy pages.
