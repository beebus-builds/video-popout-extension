# video-popout-extension

Pop any video into a floating always-on-top window, with volume + audio essentials.

## Install (Load unpacked)
1. Open chrome://extensions -> enable **Developer mode**.
2. **Load unpacked** -> select this folder (E:\extension).
3. Play a video -> click the toolbar button or press Alt+P.

## Features
- One-click Picture-in-Picture + per-video picker with thumbnails.
- Hover Pop button, iframe + Shadow DOM scanner, ad/DRM hints.
- Playback: play/pause, mute, volume slider, +-10s seek, speed cycle.
- Audio: volume boost to 200% + Bass / Vocal / Flat EQ.

## Permissions
ActiveTab + scripting + storage + contextMenus only. No host access, no tracking.
